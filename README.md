## Descripción

Este proyecto consiste en un sistema para administrar las reservas de canchas deportivas. Permite organizar la información de las canchas, los clientes, las reservas y los pagos.

El proyecto incluye un prototipo de lógica desarrollado en TypeScript y una estructura inicial de Angular.

## Ejecutar el prototipo TypeScript

Abrir una terminal y ejecutar:

```bash
cd prototipo-ts
npm install
npm run build
npm start
```

## Ejecutar Angular

Desde la carpeta principal del proyecto, abrir otra terminal y ejecutar:

```bash
cd frontend
npm install
ng serve
```

Abrir en el navegador:

http://localhost:4200/
